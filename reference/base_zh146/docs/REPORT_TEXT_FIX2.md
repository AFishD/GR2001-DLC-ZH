## 1. A：M249 栏错字 —— 定位 / 解码 / 继承判定 / 修法

### 1.1 条目在哪（容器 / 条目 / 偏移 / 原始字节）

| 项 | 值 |
|---|---|
| 容器 | `MENU.IMG` 条目 **#283 `EN_SPECIAL_FEATURE.XML`**（`<studio name="Weapon">` 下 `<item name="M249 班用机枪">`） |
| 条目 | **`<text>` #24**（1-based 序号；容器内 body 偏移 **21619**，长度 184 B） |
| 编辑点 | 容器绝对偏移 **21634** = body + 15 |
| GR_ZH133 原始字节（该段） | `AD C6 AC BF B1 A4 A2 B6 AB A1 AB BE AD CB` |
| GR_ZH134 目标字节 | `AD C6 AC BF B1 A4 A2 A4 C6 A1 AB BE AD CB` |
| 差异 | **2 字节**：`B6 AB` → `A4 C6`（**等长原位改写**，整条 `<text>` 长度不变） |

### 1.2 按引擎规则逐字解码（图集 + FT 记录；K2 几何 `x=16*(slot%64)`, `y=yrow(slot//64)`）

引擎口径：`byte < 0x80` → ASCII（走 FT 记录）；`0xA1 ≤ lead < 0xBA` 且 `(lead,trail)` **已在 pair_of 里** → 对偶码，`slot=(lead-0xA1)*94+(trail-0xA1)`；否则单字节码。

| 单元 | GR_ZH133 字节 | 槽 / 码 | 槽里现在的字形 | 意图字 | 状态 |
|---|---|---|---|---|---|
| （ | `AD C6` | slot 1165 | （ | （ | ✓ |
| 班 | `AC BF` | slot 1064 | 班 | 班 | ✓ |
| 用 | `B1 A4` | slot 1507 | 用 | 用 | ✓ |
| — | `A2 B6` | slot **115** | **突** | 自（应为 `A2 A4` → slot 97） | ✗ |
| — | `AB A1` | slot **940** | **眼** | 动（应为 `C6` → 单字节码 198） | ✗ |
| — | `AB BE` | slot **969** | **借** | 武（应为 `A1 AB` → slot 10） | ✗ |
| 器 | `BE` | 单字节 190 | 器 | 器 | **丢失**（被 `AB BE` 吃掉） |
| ） | `AD CB` | slot 1170 | ） | ） | ✓ |

⇒ 引擎在这条上画的是 **`M249 SAW（班用突眼借）`**（与用户报障逐字一致）。
修后 = **`M249 SAW（班用自动武器）`**（= 用户译文；英文原文 `The M249 SAW (Squad Automatic Weapon) …`）。
实证图：`work\builds\GR_TEXTFIX2\out\m249_zoom.png`（四盘并排）、`out\v134_m249.png`（修后，用 134 自己的图集渲染）。

### 1.3 「错字 = 目标字 + 偏移 K」的定量关系 —— **不是固定槽偏移，是字节位移**

不是「每个字被换成另一格字形」那种固定 K：错字的槽与意图槽的差是 `+18 / +930 / +959`，**没有共同 K**。
真实关系是**配对流的 1 字节错位**：删掉 1 个字节后，后面所有对偶码的 `(lead,trail)` 全部重新配对。

### 1.4 它是怎么变成现在这样的（三段时间线，逐字节可复现）

| 盘 | 该段字节 | 引擎实际画出来 |
|---|---|---|
| `GR_REBUILD2400`（未打补丁基底，`d7f83d7e…`） | `AC BF B1 A1 A4 A2 A4 C6 A1 AB BE` | `班 △ 起 心 武 器` |
| `GR_ZH129` | 同基底（逐字节相同） | `班 △ 起 心 武 器` |
| `GR_ZH130`（字形右缘修复） | `AC BF B1 A1 A4 A2 **B6 AB** A1 AB BE` | `班 △ 起 心 武 器` |
| **`GR_ZH133`**（陈旧码表追平） | `AC BF B1 A4 A2 **B6 AB** A1 AB BE` | **`班 用 突 眼 借`** |
| `GR_ZH134`（本轮） | `AC BF B1 A4 A2 **A4 C6** A1 AB BE` | **`班 用 自 动 武 器`** |

三段机理（**每一步都有盘上字节证据**）：

1. **原始缺陷（继承，≤ GR_ZH126 就存在）**：该条目的正文字节 = **正确文本 + 1 个多余的 `0xA1`**。
   证据：把 ZH129 的 `B1 A1 A4 A2 A4 C6` 删掉那个 `A1` 就**精确得到** `B1 A4 A2 A4 C6` = `用 自 动`（当前码表口径）。
   这是**系统性注入缺陷**，同一形状在 SFXML 里共 **59 处**（用×42 / 练×15 / 键×2，见 `patch_zh133_stale_hashr.py:plan_insert_fix`）。
2. **GR_ZH130 的连带改写**：右缘修复把那 36 个 col-63 槽换位，其中 `心` 由 `A4 C6`（slot 319 = row4 col63）搬到 `B6 AB`（slot 1984）
   （charset `_glyph_edge_zh130.pair_moves` 第 5 条，逐字段核对一致）。该轮**忠实跟随了引擎的误读**——
   被错位流解出来的那一格本来就"是心"，于是把 `A4 C6` 改成了 `B6 AB`。**这一步把「删 1 字节就能复原」的性质破坏了。**
3. **GR_ZH133 的插入型修复**：规则 `B1 A1 T → B1 T` 在偏移 13 命中（`(B1,A4)=用` 已登记）⇒ 删掉 `A1`。
   若第 2 步没发生，这一删就**正好复原** `用自动`；但第 2 步已经把尾巴改成 `A2 B6 AB`，于是重新配对成 `突 眼 借`。

**⇒ 继承判定（回答「继承还是本轮引入」）：**
* **缺陷本身是继承的**：`M249 SAW（班用自动武器）` 这个字符串**从来没有**在任何一张中文盘上正确显示过
  （ZH126/127/128/129/130/131 全是 `班△起心武器`）。
* **但用户看到的那三个字「突眼借」是本轮（GR_ZH133）引入的**：ZH133 的删字节把旧形态 `班△起心武器` 变成了 `班用突眼借`。
  两者都不是正确文本 ⇒ **结论 = 「继承缺陷 + 133 轮改变了表现形式」**。

### 1.5 修法（根因级）

不迁槽、不动图集：**把该单元的码位改回当前码表的正确码**（`自=A2A4` slot 97 / `动=单字节码 C6`），
即 `B6 AB → A4 C6` 两个字节。**ELF 0 字节、图集 0 字节、容器槽 49700 B 不变、解压总长 116486 B 不变。**

## 2. B：三处「插入型残留」补齐（同类根因，一并修）

133 那轮的 `plan_insert_fix` 只删 **1 个** `0xA1`；本轮逐处复核 59 个站点后发现，**三处的残留不止 1 字节**——
历史迁移把 `。何` 碎片留在了流里，导致删完仍读不通。逐处与英文原文对照后补齐：

| 条目 | ZH133 显示 | ZH134 显示 | 字节改动 | 依据 |
|---|---|---|---|---|
| `T0025` MG3 通用机枪 | `且未配备专用。何供弹箱。` | `且未配备专用供弹箱。` | 删 `A8 B9 FD`（。何，−3 B） | EN `…and did not have a box for feeding ammunition into the weapon.` |
| `T0030` Groza | `《荒漠围攻》中使用。何正是这一型号。` | `《荒漠围攻》中使用。正是这一型号。` | 删 `FD`（何，−1 B） | EN `This last variant is the one used in Desert Siege.` |

### 3.4 机理判定（把「行数/前导换行/行长变化」这条线关掉）

**(a) 引擎不丢行。** `RSHTML::CreateStrings` 把每一行都放进 `comp+0x110` 的 RSArray，`comp+0x114` = **完整行数**
（`docs\_obsolete\REPORT_sf_nowrap.md` §2.4 的 EE RAM 实测：特别收录「开发访谈 1」内页 = **117 行 = 该条 CSV 行数**，一行不少）。
⇒ 截断**不是**「引擎按行数上限砍文本」。

**(b) 面板几何。** 同一份 EE RAM 实测：特别收录内页文本框 = **W=`comp[0x40]`=270 × H=`comp[0x44]`=190**，
行高 `comp[0xF8]`=18 ⇒ 一屏 **约 10.5 行**。13 条专家档案的**每一页**都超过 10 行
（最短的 medical 页 8 行，history 页 17–27 行）⇒ 必然有内容落在框外。
