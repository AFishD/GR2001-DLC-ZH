## G. 未达成项（如实）

1. **「差异只在标题/LANG/空行相关屏」未能实机证明**：`nav_menu_only` 只覆盖冷启动 → 标题屏 → 主菜单，到不了「特别收录/简报」屏。本轮证据 = 逐条回读（2406/2406）+ FF 门禁 + 1 帧粒度（91 帧差异全部是继承的时序/闪烁）。要拍那些屏需要一条 15k–31k 帧、历史上一向不稳的导航脚本（`nav_sf*.txt`），本轮未启。
2. **标题栏宽度 / `×` 行宽**：只能实机看（§F.3），离线只给了像素预算实测。
3. **`EN_STRINGS.TXT` 2 条 Kit 名**（`Grenades Only` / `No Explosives`）：无注入通道（`inject_text_csv.py` 只认 LANG/SFXML），槽位已占满 ⇒ 只给规格，未落地。
4. **`著` = 0xFF**：`显著/卓著` 仍以 `明显/卓越` 表达（22 处）；根治需改 ELF `0x00544588 (lb→lbu)`，本轮不动 ELF。
5. **`SFXML:T0010`（M18 Claymore）正文**：JSON 无覆盖 ⇒ 保持原样（标题已统一）。
6. **`手雷` 24 处训练文案**：按 `REPORT_TERM_UNIFY` A.4 的裁决保留口语（正名「破片手榴弹」只用于标题/正文正式处）。
7. **`EN_STRINGS.TXT` 双拷贝不一致**（MENU 中文 / GR 英文）：既有风险，本轮未动。
