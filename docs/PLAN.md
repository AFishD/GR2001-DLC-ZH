# PLAN —— 总体计划与阶段

> 目标：把《幽灵行动：丛林风暴》(PS2, SLUS-20820, 美版) 完全汉化，
> 产出**从英文原盘一键可复现**的汉化 ISO，并用硬断言自证。

## 0. 已知事实（侦察阶段，2026-10-21）

* ISO：1,229,225,984 B（600,208 扇区）；卷标 `SLUS_20820`；ELF `SLUS_208.20`（LBA 296，5,319,720 B）。
* 只有一个大容器 `GR.IMG`（LBA 61000，1,104,291,830 B），内含 **3,111** 个资源条目；
  条目表格式与本体完全一致（`+0x830`，每项 12×u32=48 B；名字表 `+0x10` 起 `\0` 分隔）。
* 无 `MENU.IMG`：菜单/文本/字库资源全部在 `GR.IMG` 内：
  * `EN_STRINGS.RES` = GR#576（LANG 语言表，67 组 / **2,971 条** / 159,071 文本字节）
  * `FONT.RES` = GR#580（字库定义，3 个 face）；字形图集在 `COMMON.PAK` = GR#9 的
    `new_font_revised` 记录（原版 512×512 PSMT8，262,160 B 像素）
  * `EN_SPECIAL_FEATURE.XML` = GR#3101（133,359 B）
  * `*.MIS` 45 个、`*.XML` 11 个、`*.ATR` 766 个
* 本体工程（`reference/`）的工具链几乎全部适用：
  `tcslib` 直接可解析资料片的 IMG/LZO/LANG/SFXML/FONT.RES/PAK。

## 2. 分支策略

* `main`：初始基线（P0）+ 每次**验证通过**后由 `test/*` 合并。
* `test/analysis`：P1 分析工具与文档（本工程主要工作分支）。
* `test/build-font`：字库阶段自证（25/25）。
* `test/build-elf`：ELF DBCS v2 补丁 + 字库阶段自证（27/27）。
* `test/build-text`：文本注入 + 全量汉化 ISO v1 自证（37/37）。
* `test/final`：最终候选版本（审计 + 实机验收）。
* 合并方式：`git merge --no-ff`，合并前跑该分支的硬断言（verify.py）。

## 3. 质量门（继承本体工程）

1. 基底只能 = 英文原盘（sha256 校验）。
2. 每个构筑阶段比对声明 sha256，不符立即停止。
3. 文本区零 `0xFF`。
4. **Game CRC 尽量不变**（优先数据层方案）；若必须改 ELF，单独论证并记录。
5. 任务名 45/45 中文、0 英文。
6. 字库：所有译文用字都能在盘上画出来（零缺字断言）。
7. 产物 ISO 的 ISO9660/ELF/容器可解析性复查。

## 4. 免责 / 范围

* 贴图内烘焙英文（如有）单独列清单，能改则改、不能改则记录（不假装完成）。
